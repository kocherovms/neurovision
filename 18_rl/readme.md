**КОНТЕКСТ**

В ходе игрищ с 17_rl стало понятно, что требуется явное моделирование мира, чтобы агент был успешным. Или иначе вывод latent variables. TEM/DSWM - в эту тему. Явное выделение модели мира позволит агенту адаптироваться к новым условиям (например, дневной -> ночной уровень, без перетирания старого опыта).

**ИДЕЯ**

На примере игры во Frostbite проработать явное моделирование мира.

**ЗАДАЧИ**

1) явное выделение модели мира
2) прикручивание через PPO оптимизации политки
